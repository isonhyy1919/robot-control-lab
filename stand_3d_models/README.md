# 台架零件 3D 模型

本目录存放机器人控制台架的 STEP 格式零件模型，便于结构设计、装配检查和后续加工。

## 文件说明

- `8080.STEP`：8080 铝型材零件。
- `底座.STEP`：台架底座。
- `固定码.STEP`：连接与固定零件。
- `机械臂法兰.STEP`：机械臂安装法兰。
- `转接座.STEP`：机械臂与台架之间的转接零件。

## 设计来源

本目录中的台架零件 3D 模型由 **王加州** 绘制和设计。

## 使用说明

STEP 文件可使用 SolidWorks、FreeCAD、Fusion 360、CATIA 等 CAD 软件打开。加工或装配前，请根据实际设备再次核对尺寸、公差、安装孔位及材料要求。
